# Product Review Sentiment Analysis (Amazon/Flipkart)

## Project Overview

The **Product Review Sentiment Analysis** project uses Machine Learning to classify customer reviews as positive, negative, or neutral. It helps understand customer opinions based on review text.

## Objective

* Analyze customer reviews.
* Predict the sentiment of a review.
* Learn Natural Language Processing (NLP) and Machine Learning techniques.

## Technologies Used

* Python
* Machine Learning
* Pandas
* NumPy
* Scikit-learn
* Natural Language Processing (NLP)
* Jupyter Notebook / VS Code

## Project Status

🚧 This project is currently under development.

## Future Scope

* Improve prediction accuracy.
* Support reviews from multiple shopping platforms.
* Build a simple web application for sentiment prediction.
* Add visual reports and graphs.
